# Capturas de proyectos

Coloca aquí capturas propias de cada sitio (recomendado: 1200×750, `.jpg` o `.webp`)
y referéncialas en `scripts/data.js` con el campo `image`, por ejemplo:

```js
image: 'assets/img/proyectos/cuyox3-dental.jpg'
```

Si un proyecto no tiene `image`, el sitio muestra una captura automática generada
a partir de su URL (servicio mShots de WordPress.com). Los sitios con inicio de
sesión mostrarán su pantalla de acceso, así que conviene subir una captura propia
del panel para esos casos.
