Otros clientesTienda en línea

Candylandia Store

Tienda de dulces importados con catálogo administrable y pedidos por WhatsApp. Empezó como un sitio en HTML, CSS y JavaScript y la migré a una arquitectura con React y una API en FastAPI, para que el catálogo viva en una base de datos y los cambios del panel se publiquen al instante.

Qué hace

  • Catálogo de productos con categorías, etiquetas y fotos
  • Botón «Lo quiero» que arma el pedido por WhatsApp
  • Secciones de mayoreo, testimonios, preguntas frecuentes y boletín
  • Panel de administración con inicio de sesión para gestionar productos, categorías, etiquetas e imágenes
  • Exportación e importación del catálogo en Excel y PDF, y bandeja de mensajes de contacto
Cómo funciona
  1. El frontend en React 18 + Vite se compila y lo sirve Nginx dentro de un contenedor.
  2. Una API en FastAPI (sobre Gunicorn) expone el catálogo y el panel; usa SQLAlchemy y Alembic sobre PostgreSQL.
  3. El panel se protege con tokens JWT y contraseñas cifradas con bcrypt; las fotos se procesan con Pillow.
  4. Todo corre con Docker Compose en un VPS, detrás de Nginx con HTTPS de Let's Encrypt, y se despliega con un solo script (deploy.sh).
